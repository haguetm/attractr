<h1 align="center">Attractr</h1>

<p align="center"><strong>Dis ce que tu cherches, en une boisson.</strong><br/>
L'appli de rencontre où l'intention est claire dès le premier regard.</p>

---

## L'idée

Sur la plupart des applis de rencontre, on découvre trop tard que l'autre ne cherche pas la même chose. Sur Attractr, **chaque profil affiche une boisson qui annonce son intention**, et **le feed ne montre que des personnes compatibles**. Plus de malentendus, plus de temps perdu.

| Boisson | Ce qu'elle dit |
|---|---|
| 🍷 **Vin** | Je cherche une relation sérieuse |
| ☕ **Café** | Je ne sais pas encore : sérieux ou léger, on verra |
| 🍸 **Cocktail** | Je cherche une rencontre sans engagement |
| 🍺 **Bière** | Je cherche des amis, uniquement |

On choisit une boisson, ou deux si l'une d'elles est la Bière (par exemple Vin + Bière : une relation sérieuse, et des amis aussi). Les boissons sont des symboles, pas des invitations à boire : des icônes sans alcool sont proposées à qui le souhaite.

---

## Le meilleur des applis de rencontre, sans leurs défauts

Attractr reprend ce qui fonctionne dans les applis de rencontre et écarte ce qui agace leurs utilisateurs.

| Ce qu'on reprend | Ce qu'on laisse de côté |
|---|---|
| Un feed de profils proches, simple à parcourir | Des profils qui ne cherchent pas la même chose que toi : **ils n'apparaissent jamais** |
| Les likes ciblés sur une photo ou une réponse, pour engager la conversation | Les matchs qui dorment : **24 h pour envoyer le premier message**, puis une relance « à ton tour » |
| Les questions de profil qui révèlent une personnalité | Les faux profils : **selfie de vérification obligatoire** et contrôle d'âge |
| Un abonnement Premium qui apporte un vrai confort | Les prix qui changent selon ton âge ou ton profil : **prix unique pour tous** |
| Des options payantes à l'unité (Boost) | Les abonnements impossibles à quitter : **résiliation en un clic** |
| Une expérience gratuite réellement utilisable | Les formules gratuites bridées au point d'être inutilisables : **chat, matchs et sorties restent gratuits et illimités** |
| Les profils vérifiés mis en avant | Les notes de beauté et les classements de physique : **interdits**, y compris dans l'analyse IA |
| La localisation pour trouver des gens près de chez soi | Ta position exacte exposée : **arrondie à environ 1 km**, distances affichées par tranches |
| Les fonctions d'un réseau social qui servent la rencontre (amis, sorties) | Le reste du réseau social : **pas de fil d'actualité, pas de publications, pas de messages hors match** |
| L'inclusivité des genres et des façons d'aimer | Exposer tes données sensibles : **chiffrées, jamais affichées, jamais envoyées à des outils de mesure** |

## Ce que fait l'appli

### Un profil qui dit l'essentiel
- Prénom, âge (18 ans minimum), genre, photos et **3 questions écrites** choisies dans une liste.
- **Genres recherchés** : ils font le matching, mais ne sont jamais affichés.
- **Situation** : célibataire, en relation ouverte ou polyamoureuse avec l'accord de ses partenaires, ou en couple fermé (Bière uniquement, pour se faire des amis).
- **Façon d'aimer** : une relation à la fois, ouvert·e à voir, relation ouverte ou polyamour, avec sa propre compatibilité.
- **Polyamour** : on peut préciser qui on cherche (une personne, deux, trois ou plus, avec les genres souhaités).
- **Ouvert·e aux couples** : on choisit si des comptes de couple peuvent nous être présentés.
- **Orientation** : facultative, masquable, sans aucun effet sur le matching.

### Une découverte qui ne montre que des profils compatibles
- Le feed filtre selon la distance, les genres recherchés **des deux côtés**, la boisson, la façon d'aimer et ce qu'on cherche en polyamour. Les profils déjà vus, bloqués ou signalés sont exclus.
- Si les profils manquent, **le rayon s'élargit automatiquement**, avec un message d'attente au lieu d'un écran vide.
- **Badge d'activité réelle** : on voit si la personne répond encore.

### Des likes, des matchs, des conversations
- **25 likes par 24 h** en gratuit, illimités en Premium. Le chat, les matchs et les réponses ne sont jamais limités.
- **Likes ciblés** sur une photo ou une réponse.
- **24 h pour lancer la conversation** après un match, avec une prolongation possible.

### Les comptes de couple
- Deux comptes vérifiés reliés en un profil commun, avec le badge « Compte couple ».
- Chaque like du couple demande l'accord des deux, et chaque photo commune aussi.
- **Chat transparent** : un bandeau rappelle que les deux partenaires voient la conversation.
- Chacun peut quitter le compte couple en un clic, et personne ne voit les likes ni les matchs personnels de l'autre.

### Amis et sorties à plusieurs
- Jusqu'à **10 amis**, ajoutés par lien ou pseudo (jamais par import de contacts).
- Après un match, on propose une **sortie de 3 à 8 personnes** : chacun invite ses amis, qui reçoivent une carte « je viens / je ne viens pas » **sans accès aux profils**. Un avis privé est demandé après la sortie.

### Les chats de groupe (Premium)
- **Groupes romantiques et polyamoureux** (6 personnes maximum) : chaque membre a matché avec tous les autres, et l'appli le vérifie à chaque ajout.
- **Groupes de potes** en Bière (8 personnes maximum), sur invitation et avec l'accord du groupe.
- Aucun groupe public, aucune recherche de groupes.

### L'analyse IA du profil
- Pour chaque photo, un point fort et un conseil concret (lumière, cadrage, variété), plus un **ordre de photos conseillé**.
- Pour la bio : repérage des clichés et réécriture proposée **dans ton ton**.
- **Jamais** de note de beauté, de commentaire sur le corps, l'âge ou l'origine, ni de déduction sur l'orientation, la santé ou la religion. Une vérification automatique rejette toute réponse qui ne respecte pas ces règles.
- Consentement séparé, aucun entraînement sur tes photos, suppression après l'analyse.

### Le parrainage
- **Parrain abonné** : 1 mois offert par filleul validé, jusqu'à 6 mois par an. Le filleul reçoit aussi 1 mois de Premium.
- **Parrain non abonné** : une réduction sur son futur abonnement, et 50 % sur le premier paiement du filleul.
- Le parrainage est **anonyme** : le parrain voit seulement « inscrit et vérifié ».

## Sécurité, confiance et vie privée

- **Strictement réservé aux adultes** : âge déclaré, estimation de l'âge à partir du selfie, revue humaine des cas douteux. Un bouton « suspicion de mineur » est présent sur chaque profil et chaque chat, et ces signalements sont traités en priorité.
- **Selfie de vérification obligatoire**, modération des photos, détection des arnaques (liens suspects, demandes d'argent).
- **Signalement, blocage, mode pause, blocage des contacts du téléphone.**
- **Suppression du compte en un clic**, avec un effacement réel des données.
- **Données sensibles chiffrées** (genres recherchés, situation, façon d'aimer, orientation), protégées par des règles d'accès testées automatiquement. Elles n'apparaissent jamais dans les outils de mesure, les journaux ou les notifications.
- **Consentements séparés et retirables en un clic.** Chaque accès interne aux données est journalisé.

## Pour les développeurs

### Stack
- **Mobile** : Expo (React Native) SDK 57 + TypeScript, Expo Router, i18next (textes en français).
- **Backend** : Supabase en région UE : Auth (SMS), Postgres + PostGIS, Realtime, Storage, règles d'accès par ligne (RLS) sur toutes les tables, Edge Functions (Deno) pour tous les prestataires externes.
- **Paiements** : RevenueCat. **Notifications** : Expo Notifications. **Mesure** : PostHog (UE) et Sentry.
- Les règles métier vivent dans la base (SQL), avec un miroir TypeScript pour l'interface. Chaque prestataire externe est derrière une interface, avec une version factice en développement.

### Structure du dépôt
```
apps/mobile/          Appli Expo (écrans dans src/app, textes dans src/i18n/fr.json)
packages/shared/      Types du domaine et règles partagées (validées par Vitest)
supabase/migrations/  Schéma, RLS, fonctions SQL : la source de vérité des règles
supabase/tests/       Tests pgTAP (règles métier et règles d'accès)
supabase/functions/   Edge Functions (localisation, suppression de compte…)
supabase/seed/        Générateur des 100 profils fictifs
docs/                 Spécification, décisions, architecture, conservation des données
```

### Démarrer
Prérequis : Node 22 et Docker.

```bash
npm install
npm test                       # tests TypeScript (logique partagée, seed, appli)
npm run functions:test         # tests des Edge Functions (Deno via npx)
npm run db:start               # Supabase en local
npm run db:reset               # migrations + 100 profils fictifs
npm run db:test                # tests pgTAP
npm run db:test:lite           # mêmes tests sans Docker (Postgres embarqué PGlite)
npm run functions:serve       # Edge Functions en local (2e terminal)
npm run mobile                 # appli (configurer apps/mobile/.env avant)
```

Pour se connecter en local, utilise le numéro fictif **06 39 98 00 00** avec le code **123456** (aucun SMS n'est envoyé).
